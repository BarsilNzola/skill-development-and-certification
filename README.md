# Code Gears: Skill Development and Certification Platform

**Live Site:** [Visit Code Gears](https://skill-development-and-certification.onrender.com/logout/)  
**GitHub Repo:** [Code Gears on GitHub](https://github.com/BarsilNzola/skill-development-and-certification/tree/deployment-config)

---

## 🚀 Overview

Code Gears is a web-based, self-paced learning platform aimed at equipping learners—especially in Africa—with the technical skills necessary for today’s digital world. The platform currently offers free Web Development training and plans to expand with additional modules in:

- Introduction to Python
- AI Prompt Engineering
- Web3 and Blockchain Technologies

Learners can progress at their own pace, receive mentorship support, and earn certificates upon completion.

---

## 🧠 Current Features

- ✅ Free access to structured **Web Development** content
- ✅ Learner dashboard with progress tracking
- ✅ Certification upon module completion
- ✅ Secure login and registration
- ✅ User-friendly interface

## 📚 Upcoming Modules (Planned Within 2 Months)

### 1. **Introduction to Python**
- Learn programming fundamentals.
- Understand data types, control flow, and functions.
- Prepares learners for backend development and scripting roles.

### 2. **AI Prompt Engineering**
- Understanding how to interact with LLMs (like ChatGPT).
- Designing, testing, and optimizing AI prompts.
- Skills in high demand in AI product teams.

### 3. **Web3 and Blockchain**
- Basics of blockchain and decentralized apps.
- How smart contracts work.
- Exposure to Ethereum, wallets, and NFTs.

## 🧪 Running Locally

```bash
git clone https://github.com/BarsilNzola/skill-development-and-certification.git
cd skill-development-and-certification
pip install requirements.txt
python manage.py runserver
```
